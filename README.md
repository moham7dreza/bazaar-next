### Advertisement shop made with Next.js
frontend of [bazaar-laravel](https://github.com/moham7dreza/bazaar-laravel) project in my repo

### Requirements
1. `NPM` and `Node` above v20

### Commands
1. run `next info` for info about next.js
2. run `next lint` for linting errors

### setup
1. run `sh fix-permissions.sh` to fix access
2. run `sh install.sh` to an init project
3. apply required changes in .env file if needed
4. goto http://localhost:3000 in your browser to see a result
